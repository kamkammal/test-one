Golden rules

  • GitHub is the single source of truth. Arena conversations are isolated sandboxes — nothing syncs between sessions except through the repo.
  • Pull before starting work; push early and often so conflicts stay small and easy to resolve in the PR.
  • One token per person, never shared. The session-start prompt re-adds the remote every time, because .git/config doesn't persist between Arena sessions.
