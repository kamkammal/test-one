From starting a conversation to creating a pull request — with the exact prompt to paste at each step. GitHub is the single source of truth; each member works in their own Arena session.

Push — writes to GitHub (needs the member's own token)
Pull / clone — reads from GitHub (token-free if the repo is public)
Copy-paste prompt for your Arena conversation

Golden rules

  • GitHub is the single source of truth. Arena conversations are isolated sandboxes — nothing syncs between sessions except through the repo.
  • Pull before starting work; push early and often so conflicts stay small and easy to resolve in the PR.
  • One token per person, never shared. The session-start prompt re-adds the remote every time, because .git/config doesn't persist between Arena sessions.

If something breaks

  • Push fails: "Permission denied" / "Resource not accessible by personal access token" → your token is read-only. Edit it on github.com (Fine-grained tokens → Edit → Contents: Read & write) — the token value stays the same, then re-send the push prompt.
  • Token expired → regenerate on github.com with the same scopes and paste the new one.
  • "Repository not found" / auth errors → re-send the session-start prompt (it re-adds the remote).
  • Merge conflict → ask the agent: "Pull main into my branch and help me resolve the conflicts."
